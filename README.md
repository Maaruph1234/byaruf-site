# ByAruf website source

React + Vite, pre-rendered for SEO.

- `npm install`
- `npm run dev` to work locally
- `npm run build` to produce `dist/` (static HTML for every page, sitemap, robots, CNAME)

The live site on GitHub Pages is the contents of `dist/` on the `main` branch.
Edit content in `src/data/` (products, services, FAQ, contact details).
